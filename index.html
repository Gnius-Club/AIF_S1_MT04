Los estudiantes podrán: comprender la descomposición de problemas y la eficiencia en la estrategia de diseño para usar Onshape mediante modelado 3D con extrusión y revolución para crear volúmenes.

🤖 Prompt de Referencia para XOLO (Solo para Maestro)

⚠️ NOTA: XOLO ya conoce el tema de esta misión. Este prompt es SOLO de referencia en caso de emergencia técnica: 
Explícame cómo se crea volumen a partir de un croquis y cuál es la diferencia estratégica entre extrusión y revolución en el modelado 3D. Analicemos criterios para decidir la mejor secuencia de modelado según la geometría del objeto.

Concepto Clave

Usar Onshape para crear formas con volumen usando herramientas de estirar (extrusión) y girar (revolución).

🧪

Experimentación

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a crear la primera versión 3D de mi proyecto en Onshape. Quiero justificar la secuencia de operaciones que elijo y reflexionar por qué es la más eficiente para mi diseño."

2. 🔬 Experimenta y descubre con tu modelo:

  • ¿Tu modelo tiene el volumen y la forma que imaginaste al inicio?
  • ¿Qué pasa si intentas cambiar una medida en el boceto original después de haber aplicado la extrusión?
  • ¿Funciona igual crear un cilindro por extrusión de un círculo que por revolución de un rectángulo?
  • Al dividir tu objeto en partes simples, ¿cómo aplicaste la descomposición de problemas en tu diseño?
  • ¿Por qué elegir una secuencia de pasos ordenada hace que tu diseño sea más eficiente y fácil de corregir?

¡Es hora de crear! Vamos a usar todo lo que platicamos con XOLO para construir nuestra primera versión 3D. El flujo es sencillo: primero ideamos con XOLO, definimos el VIBE de nuestro proyecto y él nos guiará paso a paso en Onshape. Por ejemplo, podrían diseñar un soporte para audífonos usando extrusión para la base y revolución para el poste central. Recuerden las preguntas de experimentación: ¿es esta la forma más eficiente de hacerlo? Si algo no sale como esperaban o necesitan ayuda eligiendo entre extrusión y revolución, pregúntenle a XOLO, él los ayudará a definir la mejor estrategia de diseño.
